# てんぷら職人

泡と音で揚げ頃を見極め、両面を返して、てんぷらを「カラッと」揚げる 3D Web ゲームです。
Three.js（CDN 読み込み）だけで動き、ビルドは不要です。画像・音声ファイルも使わず、テクスチャと揚げ音はすべてプログラムで生成しています。

## 言語

日本語と英語に対応しています。ブラウザの言語設定で自動に選び（日本語以外は英語）、タイトル画面の「日本語 / English」で切り替えられます（選んだ言語は記憶）。URL に `?lang=en` / `?lang=ja` を付けても切り替えられます。英語版の遊び方は [howto.en.html](https://techgymjp.github.io/templa/howto.en.html)。

## 遊び方

詳しい遊び方は [howto.html](https://techgymjp.github.io/templa/howto.html) にまとめています。

1. カウンターのお客さんが、具材のイラストの吹き出しで注文します。
2. 画面下の具材ボタンを押すと、衣をくぐらせて銅鍋へ入れます（キーボードの 1〜0 でも可）。
3. 油に浸かっている面だけが早く色づきます。鍋の天ぷらを**タップすると裏返せます**。途中で一度返して両面をきつね色に。
4. 泡が細かく少なくなり、音が高くなったら揚げ頃です。天ぷらを**右の網までドラッグ**して引き上げます。
5. 網で油を切った天ぷらは、注文したお客さんの器へ運ばれます。時間がたつと衣がしんなりします。

- 油温は店が適温に保っています。ただし鍋に入れすぎると一時的に下がり、ベチャッと揚がります。
- **揚げ時間ガイド**：営業のたびに各具材の1回目は、画面の端に「何秒で返して何秒で上げるか」の目盛りと今の秒数が出ます（PCは左端、スマホは具材ボタンの上）。
- **職人モード**：揚げ時間の表示を隠すかわりに、得点が 1.3 倍になります。
- **BGM**：J.S.バッハ「平均律クラヴィーア曲集 第1巻 前奏曲 ハ長調 BWV 846」（パブリックドメイン）を WebAudio で演奏しています。タイトル画面のチェックでオン・オフできます。

## 揚げのしくみ

- 中の火通り（cook）は時間とともに進みます。具材ごとに必要な時間が違います。
- 衣の揚げ色は両面別々に進みます。油に浸かった面は速く、上に出た面はゆっくり色づきます。
- 揚げ色（両面）・火通り・食感（油っぽさ）から 100 点満点で評価します。片面だけ濃い・白いと減点です。

## 難易度の検証

腕前の違う自動プレイヤーで営業（2分30秒）をくり返して、点数のばらつきを確かめています（ゲームの処理を描画なしで早送りして実行）。

| 腕前 | 内容 | 売上（平均） | 平均の出来 | 称号 |
| --- | --- | --- | --- | --- |
| 名人 | 理想の時間どおり（±4%）に返して上げる | 約2250 | 95点 | 名人 |
| 中級 | 時間が±20%ずれる・ときどき返し忘れる | 約1400 | 約62点 | 一人前〜板前 |
| 初心者 | 時間が±45%ずれる・半分は返さない・注文を取り違える | 約370 | 約23点 | 見習い〜駆け出し |
| でたらめ | 具材もタイミングも適当 | 約110 | 約15点 | 見習い |

- 隣り合う腕前の売上の範囲はほぼ重ならず、上手いほど確実に点が伸びます。
- 名人の腕前でも鍋に常に 6 個詰め込むと、油温が下がって平均 16 点まで落ちます（3〜4 個までが適量）。
- お客さんの待ち時間は「17秒＋揚げ時間×1.5」（えびで約34秒、かき揚げで約44秒）。手際が悪いとお客さんが帰ってしまい減点されます（名人 0.3 人、初心者 1.5 人、でたらめ 5.8 人）。
- 称号の基準：見習い 0〜／駆け出し 500〜／一人前 1000〜／板前 1500〜／名人 2000〜／天ぷらの神 2700〜（職人モードの ×1.3 が必要）

## 音

- 「営業開始」を押すと最初に「仕込み」をして、効果音（パチパチ・ジュワッ）と BGM のピアノの各音を録音済みの音として作り、全具材の衣と描画も準備してから始めます。ゲーム中は再生するだけなので、スマホでも音が割れにくく、初めて揚げる具材でもカクつきません。
- 同時に鳴る音の数に上限を設け、最後にリミッターを通して音割れを防いでいます。

## 画づくり

- 透過・屈折する油（鍋底や沈んだ具材が琥珀色に透ける）
- 天井照明を映り込ませる環境マップ、柔らかい影、環境遮蔽（GTAO）、光のにじみ、周辺減光
- 細かく分割した衣の凹凸、両面別々の揚げ色、揚げたての油のつや
- スマホ・小さい画面では軽量表示（半透明の油、後処理なし、解像度・影・泡を控えめ）。`?q=low` / `?q=high` で切り替え可。PC でも描画が重いと自動で画質を下げます

## 起動

ES Modules を使うので、ローカルの HTTP サーバーで開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## Android アプリ

[Capacitor](https://capacitorjs.com/) でゲームのファイルをアプリに同梱し、Android アプリにしています（オフラインで遊べます。three.js とフォントもアプリに同梱）。
構成は techgymjp/jet-fighter の `docs/ANDROID_PORTING.md` と同じです。

- パッケージ名: `jp.techgym.templa`
- アプリ名: てんぷら職人（英語の端末では Tempura Master）
- 縦画面固定・全画面・プレイ中は画面を消さない
- 戻るボタン: プレイ中は一時停止（一時停止中なら再開）、遊び方ではタイトルへ、タイトル・結果画面ではアプリを終了
- 別アプリに切り替えると自動で一時停止して音を止める
- シェアは Android の共有メニュー
- 遊び方はアプリの中で開く（Web 版は howto.html）
- タイトル画面にベスト記録・バージョン・プライバシーポリシー・広告の設定（EU など同意が必要な地域だけ）
- 広告（AdMob）
  - バナー: タイトル・遊び方・一時停止・結果画面の下中央（プレイ中は出さない）
  - 全画面広告: 営業開始（タイトル・遊び方から）、タイトルへ（遊び方・一時停止・結果から）、一時停止からの再開、結果からのもう一度のたびに毎回
  - リワード広告: 50 点未満で網に上げた天ぷらを、広告を見て揚げ直せる（1 営業 5 回まで。その 1 品の成績を取り消し、同じ具材の新しい 1 品を鍋に入れる。結果画面とシェア文に「やり直し N 回」）
  - 本番の広告ユニット ID は `js/ads.js`、AdMob のアプリ ID は `android/app/src/main/res/values/strings.xml`（いまはテスト用 ID）

### ビルド

GitHub Actions（`.github/workflows/android.yml`）でビルドします。

- 動作確認用 APK（テスト広告）: https://github.com/techgymjp/templa/releases/tag/android-latest
  （APK 直接: https://github.com/techgymjp/templa/releases/latest/download/tempura-master.apk）

  ![リリース画面の QR コード](docs/apk-qr.png)

- Google Play 用の署名付き AAB（本番広告）: GitHub Secrets（`ANDROID_KEYSTORE_BASE64` など 4 つ）を登録すると、Actions の Artifact に `tempura-master-release-aab` ができます

手元でビルドする場合:

```bash
npm ci
npm run android:sync
cd android && ./gradlew assembleDebug
```

## ファイル構成

- `index.html` — 画面と UI
- `howto.html` / `howto.en.html` — 遊び方ページ（日本語 / 英語）
- `js/i18n.js` — 日本語・英語の文言と切り替え
- `js/ads.js` / `js/ads-config.js` / `js/build-info.js` — 広告（アプリのみ）、広告のモード、バージョン表示
- `scripts/build-web.js` — アプリに同梱するファイルを `www/` に作る
- `android/` — Android プロジェクト（Capacitor）
- `assets/` — アイコンと起動画面の元画像
- `js/quality.js` — 画質（軽量表示）の判定
- `css/style.css` — スタイル
- `js/main.js` — ゲーム進行・揚げ物の物理・泡・湯気・お客さん・入力・後処理
- `js/scene.js` — 什器（銅の天ぷら鍋、油、網バットと天紙、衣のボウル、菜箸、付け台と器）と、表情・視線・食べる動作のあるお客さんの 3D モデル
- `js/ingredients.js` — 具材 10 種のモデル、衣の生成、揚げ具合の計算と評価
- `js/textures.js` — 槌目の銅、檜、ステンレス、土壁、布、髪、和紙、衣などの手続き生成テクスチャ
- `js/icons.js` — 注文吹き出し用の具材イラスト（SVG）
- `js/audio.js` — WebAudio で合成した揚げ音と BGM
