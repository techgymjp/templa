# てんぷら職人

油の温度と揚げ時間を見極めて、てんぷらを「カラッと」揚げる 3D Web ゲームです。
Three.js（CDN 読み込み）だけで動き、ビルドは不要です。画像・音声ファイルも使わず、テクスチャと揚げ音はすべてプログラムで生成しています。

## 遊び方

1. カウンターに座ったお客さんが、具材のイラストの吹き出しで注文します。
2. 画面下の具材ボタンを押すと、衣をくぐらせて銅鍋へ入れます（キーボードの 1〜0 でも可）。
3. 具材ごとに適温があります。火加減のスライダーで油温を合わせます。具材をたくさん入れると油温が下がります。
4. 泡が細かくなって音が高くなったら揚げ頃です。鍋の天ぷらをタップ（クリック）して引き上げます。
5. 網の上で油を切った天ぷらは、注文したお客さんの器へ自動で運ばれます。時間がたつと衣がしんなりします。

- **衣を一滴**：衣をたらして油温を見ます。底まで沈めば低温、途中で浮けば中温、表面で散れば高温。
- **天かすをすくう**：油に散った天かすを取り除きます。
- **職人モード**：温度計と揚げ時間を隠すかわりに、得点が 1.3 倍になります。

| 具材 | 適温 |
| --- | --- |
| ほたて・牡蠣・えび | 180℃ |
| 穴子・きす・なす | 175℃ |
| れんこん・かき揚げ | 170℃ |
| ししとう・まいたけ | 165℃ |

## 揚げのしくみ

- 中の火通り（cook）は油温にほぼ比例して進みます。
- 衣の揚げ色（brown）は油温に対して指数的に進みます（15℃ 上がるごとに 2 倍）。
- そのため、適温より高いと「外は焦げて中は生」、低いと「白っぽく油っぽい（ベチャッ）」になります。
- 揚げ色・火通り・食感（油っぽさ）から 100 点満点で評価します。

## 起動

ES Modules を使うので、ローカルの HTTP サーバーで開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。GitHub Pages などの静的ホスティングにそのまま置けます。

## ファイル構成

- `index.html` — 画面と UI
- `css/style.css` — スタイル
- `js/main.js` — ゲーム進行・揚げ物の物理・泡・湯気・お客さん・入力
- `js/scene.js` — 什器（銅の天ぷら鍋、油、網バットと天紙、衣のボウル、菜箸、付け台と器）とお客さんの 3D モデル
- `js/ingredients.js` — 具材 10 種のモデル、衣の生成、揚げ具合の計算と評価
- `js/textures.js` — 槌目の銅、檜、和紙、衣などの手続き生成テクスチャ
- `js/icons.js` — 注文吹き出し用の具材イラスト（SVG）
- `js/audio.js` — WebAudio で合成した揚げ音
